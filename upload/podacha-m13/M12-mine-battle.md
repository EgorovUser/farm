# M12 — Шахта: автобой в 3 направлениях, мобы, боссы

> Фаза 4 · объём M · вход: 01-CORE, 02-BUSES, 03-DATA, M01, M02, M03, этот файл. Боевая математика — ЧИСТАЯ функция `(state, rng) → state`; мобы/боссы/элиты — только данные.

## 1. Цель модуля

Пошаговый **автобой**: и атака, и блок выбираются случайно из трёх направлений — верх / центр / низ. Совпадение направления атаки с направлением блока = урон не проходит. Роль игрока — не ручной выбор, а ПРЕДРАСПОЛОЖЕННОСТЬ вероятностей через снаряжение и ривен-карточки.

## 2. Доступ и слои

- Вход: кирка в экипировке (прочность −1 за добычу), энергия ≥ 20 (M01), с собой — оружие, броня, щит, помощники (M13).
- Слои шахты. Слой n+1 открывается: (а) победа над боссом слоя n (даёт ачивку-флаг через M15) И (б) тир кирки (слой 1–2 — любая, 3–4 — железная+, 5–6 — стальная+, 7+ — мифриловая+). Тир кирки растёт заточкой (M10: 10 уровней = +1 тир) и крафтом новых (M09) — обе проверки через `Requirement`-оценщик данных.

## 3. Раунд боя

```
1. Атакующий роллит attackDir ∈ { top, mid, bottom }
2. Защищающийся с щитом роллит blockDir; без щита блок невозможен
3. attackDir == blockDir → БЛОК: урона нет; иначе урон:
   damage = atk × 100 / (100 + def)        (округление вниз, минимум 1)
   крит: base 5% (через шину) → урон ×1.5
4. Стороны чередуются; первым бьёт более быстрая сторона
```

**Участие игрока через снаряжение (всё — модификаторы шины):**
- тир щита даёт «чутьё»: `mine.blockSense` — шанс подтянуть ролл блока к реальному направлению атаки (+5%/тир свыше честных 1/3);
- карточки заточки «Вещий удар» (M10/M03): 20% увидеть `attackDir` до раунда (стат, который читает движок);
- зелья/алтари смещают крит/урон (`mine.crit`, `mine.damage`).

## 4. Мобы и боссы (content/mobs.ts)

- Типы: паук (быстрый, слабый), летучая мышь (15% уклонение — блок без щита), слизень (толстый), скелет-мечник, копейщик, голем (мини-босс), кобольд-шаман (бафает других). Элитные модификаторы: «ядовитый» (урон по времени — модификатор с длительностью), «панцирный» (+def), «стая» (2 цели).
- HP масштаб слоя: `mobHP = 50 × 1.6^(слой−1)`. Атаки мобов — паттерны `attackDirs` по раундам (данные).
- Дропы: руда по слою, золото, таблица предметов, трофеи (коллекция/ачивки). Событие `mine.enemyKilled` с раскладом.
- **Боссы** — конец слоя, уникальная механика фазами (данные): паучья королева (замораживает одно направление блока на 3 хода — модификатор), каменный владыка (пропускает удар, потом двойной), глубинный змей (вызывает элиток). Победа: гарантированный предмет тира A+, ачивка-гейт следующего слоя, 100 XP. Проигрыш = обычная смерть забега (M13).

## 5. Урон игроку и смерть

HP игрока — M01 (в шахте НЕ регенится). `player.hpChanged` с тегом `death` → M13 завершает забег с потерей 20% рюкзака и вылетом. Больше никаких штрафов (cozy-правило). Помощники продолжают бой только до выхода из раунда — забег завершается у всех.

## 6. Интеграция

- События: `mine.runStarted` (слой, состав), `mine.turnResolved` (раунд, направления, урон, блок — для лога честности), `mine.enemyKilled`, `mine.bossKilled`, `mine.runEnded` (лут, причина выхода).
- Провайдер: `mineGearProvider` (экипировка в забеге уже действует через M02 `equipmentProvider` — сюда попадают только бафы забега M13).
- Debug: `mine mob <id>`, `mine fight <mobId> [--seed S]`, `mine boss <layer>`.

## 7. Приёмка и тесты

- [ ] Бой — чистая функция: фиксированный сид → идентичный лог боя (golden-тест).
- [ ] Блок при совпадении: частота блоков ≈ 1/3 + blockSense (монте-карло, допуск хи-квадрат).
- [ ] Формула урона и крита покрыты; минимальный урон = 1.
- [ ] Боссы: каждая фазовая механика воспроизводится по данным (новый босс = новые данные, без кода).
- [ ] Смерть: событие `player.hpChanged(death)` обрабатывается M13 — M12 сам не решает судьбу забега.
- Границы: карта/события/помощники — M13; экипировка — M02; ачивки — M15.

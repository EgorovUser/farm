# M13 — Шахта: карточный рогалик, факел, помощники

> Фаза 4 · объём L (2 подзадачи) · вход: 01-CORE, 02-BUSES, 03-DATA, M12, этот файл. Слой над боем: генерация забега из карт, события, бафы забега, наёмники со страхами и репутацией.

## 1. Цель модуля

Забег = прохождение слоя: **12 карт колонками по 3** («выбор из N» на каждой развилке), в конце — босс. 60% карт открыты, 40% скрыты; факелы вскрывают скрытые. Атмосферный статус слоя («холодный», «тёмный», «ядовитый», «жаркий») влияет на помощников и подсказывает сборы. Ежедневный бустер «Насыщенность шахты»: первый забег дня +10% руды (модификатор дня).

## 2. Карты (content/mineCards.ts — только данные)

| Карта | Эффект |
|---|---|
| Пустая пещера | немного XP |
| Рудная жила | мини-игра добычи (auto до фазы 6): тир руды = слою |
| Сундук | лут; 15% ловушка (урон) |
| Обвал | урон HP, потеря 1 карты из следующих на выбор |
| Моб / элита | бой (M12) |
| Босс | финал слоя (M12) |
| Алтарь | баф забега за жертву (золото/HP/предмет) — временный модификатор с `duration: runs` |
| Родник | +50% HP |
| Костёр | чекпойнт: при смерти потерять 5% вместо 20% |
| Торговец-крот | магазин в шахте (зелья, факелы, свиток выхода) — наценка через PriceBus |
| Заброшенный лагерь | находка + мини-событие с выбором |
| Лестница вверх | добровольный выход со всем лутом |

## 3. Жизнь забега

- Генерация слоя по сиду `(saveId, layer, runNumber)` — воспроизводима. Прогресс колонок между забегами НЕ сохраняется (рогалик), но ачивка «победил босса n» — навсегда (флаг M15).
- Лут копится в `runBag` (рюкзак забега, слоты = базово + «Рудный вагонёт»), выдаётся на выходе (лестница — 100%, смерть −20%, костёр −5%).
- Улучшения шахты: Барак наёмников (открывает помощников), Лифт (старт с колонки 4 после победы над боссом), Вагонёт, Освещение (−25% скрытых карт — `inc` к шансу «открытости»), Оборудование лагеря (реген 1 HP / 3 хода в забеге), Отряд (+1 слот помощника, старт 1, кап 3).
- Факел: расходник, вскрывает 1 скрытую карту рядом (`mine.luck.hidden` в RngBus-ролле генерации ИЛИ прямое вскрытие при использовании — по данным); находится в шахте, продаётся кротом.

## 4. Помощники (наёмники)

- Доска: 3 кандидата в день после покупки «Барака» (`dailySeed`). Профиль `HelperDef` (03-DATA §7): класс (shieldbearer / spearman / medic / looter / scout), редкость, зарплата/день, **доля награды с мобов 20%**, `atk/hp/speed`, трейты M03 в бюджете редкости, **страхи**.
- **Страхи — `Condition`, не код:** «Боится пауков» = `{t:'ctxTag', tag:'enemy:spider'}` → в боях с пауками не участвует (стоит в стороне); «Мерзляк» = слой со статусом «холодный» → эффективность 50% (модификатор с условием); «Клаустрофоб» = слой 5+ → 10% уйти из забега на середине; «Жадный» = доля +10%, но +15% золота с мобов. Всё честно показывается на карточке найма.
- Классовая логика: медик лечит раз в 4 хода, лутер бьёт слабейшего и +лут, разведчик вскрывает скрытые карты, щитоносец прикрывает блоком. Помощники бьют по общим правилам M12.
- **Репутация** (per-helper, сохраняется): +3..5 за успешный забег, +10 за босса. Уровни: −2% доля и −5% зарплата за уровень; на 50+ уникальный перк (медик: воскресить игрока 1 раз за забег с 30% HP).

## 5. Интеграция

- События: `mine.runStarted/runEnded` (состав, лут, причина), `mine.cardResolved` (карта, исход — для квестов «пройди N забегов»), `helper.hired/quit/levelReputation`.
- Провайдер: `runBuffProvider` (бафы алтарей/статусов слоя/помощников — с `duration: runs`).
- Debug: `mine gen <layer>`, `mine reveal all`, `mine torch`, `helpers board`, `helpers hire <i>`.

## 6. Приёмка и тесты

- [ ] Генерация слоя по сиду воспроизводима; доли открытых карт ≈ 60% + Освещение (монте-карло).
- [ ] Страх срабатывает как условие: тест-паук + «боится пауков» — помощник не бьёт; без паука — бьёт. НЕТ ветвлений по id страха в коде.
- [ ] Доля награды делится по вкладу; репутация режет долю/зарплату по формуле данных.
- [ ] runBag: лестница 100% / смерть −20% / костёр −5% — тест на фиксированных рюкзаках.
- Границы: боевая математика — M12; ривен-генерация трейтов — M03; UI-карты — фаза 6.

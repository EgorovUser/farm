# M06 — Загон: животноводство

> Фаза 3 · объём M · вход: 01-CORE, 02-BUSES, 03-DATA, M01, M02, M15, этот файл. По смыслу — брат фермы и озера: тот же паттерн «существо + уход + периодическая продукция + улучшения».

## 1. Цель модуля

Животные, которые периодически дают ресурсы при уходе. Покупка, кормление, продукция по часам, болезни, разведение, улучшения загона. Исполнители `pen.*` — для работников.

Экземпляр: `AnimalInstance` (03-DATA §6): качество, счастье/сытость/здоровье, `nextProduceAt` (абсолютная дата).

## 3. Уход и продукция

- **Кормить:** Корм 1 шт/животное/день; голод −30 счастья/день; голодная скотина НЕ производит.
- **Поить/чистить:** чистота падает 10/день, грязь −10 счастья.
- **Гладить:** +5 счастья, 0 энергии, раз в день (cozy-деталь).
- **Продукция:** при `satiety > 50 и health > 50` — продукт каждые N часов; качество продукта = f(качество животного, счастье, уход). Продукция копится в склад с **cap 3 сбора** (оффлайн-лимит) — в `offlineReport`.
- **Болезни:** шанс `2%/день` (выше при плохом уходе); больное не производит, лечится лекарством (крафт M09 / магазин M04) или временем.

## 4. Разведение

После улучшения «Родильный загон»: 2 животных одного вида → потомство через 48 ч. Формула качества потомства — ЕДИНАЯ с озером (см. M08 §4): `tier = clamp(max(родители) − 1 + мутацияRoll)`, мутация базово 10%. Молодняк может превзойти родителей; излишки продаются.

## 5. Улучшения загона (эффекты — модификаторы)

Амбар (+4 слота/уровень), Автокормушки (TaskRegistry: кормление при наличии корма), «Тёплый загон» (−50% болезни, +10% аппетит), Родильный загон (разведение), Пастбище-люкс (+10 счастья всем), «Второй загон» (копия — свой работник), «Симбиоз» (навоз → Удобрение фермы автоматически — событийный обмен с M05 через общие ресурсы, без импортов).

## 6. Интеграция

- TaskRegistry: `pen.feed`, `pen.clean`, `pen.collect`, `pen.pet`.
- События: `pen.produceCollected` (продукт, качество), `pen.animalSick`.
- Провайдер: `penUpgradesProvider`.
- Debug: `pen.state`, `pen.buy <species>`, `pen.collect all`.

## 7. Приёмка и тесты

- [ ] Продукция по абсолютным датам; catchUp копит до cap 3; голодная скотина не производит.
- [ ] Счастье/болезни по формулам из данных; «Тёплый загон» реально режет шанс болезни.
- [ ] Разведение: формула потомства покрыта тестом (включая мутацию вверх).
- [ ] «Симбиоз»: навоз превращается в Удобрение через TransactionService/события — ферма не вызывается.
- Границы: работники — M11; цены корма — M04; кухонные рецепты продуктов — M09.

# M07 — Рыбалка: удочки, наживки, таблицы дропа

> Фаза 3 · объём M · вход: 01-CORE, 02-BUSES, 03-DATA, M01, M02, M03, этот файл.

## 1. Цель модуля

Процесс ловли с большим честным рандомом: сначала роллится категория дропа, внутри — сущность, редкость, качество. Удочки и наживки смещают вероятности через шину удачи (RngBus), а НЕ через ветвления в коде. Часть рыб доступна только при условиях (удочка/наживка/уровень/ачивка).

## 2. Процесс

Выбрать удочку и наживку (слоты экипировки M02) → заброс (4 энергии, наживка расходуется, прочность удочки −1) → ожидание клёва 3–10 сек (`biteSeconds` рыбы) → подсечка (мини-игра «Подсечка»: удерживай маркер в зоне; зона = f(тир удочки, сложность рыбы); до фазы 6 — auto-score) → результат в инвентарь (`item.acquired`, источник `fishing`).

## 3. Таблицы дропа (content/fishing.ts)

Категории первого ролла: мусор 25 / мелкая рыба 40 / средняя 20 / редкая 8 / сокровище 4 / событие 3 (веса). Внутри категории — рыбы со своими весами; редкость роллится с весами common 60 / uncommon 25 / rare 10 / epic 4 / legendary 0.9 / mythic 0.1.

Удача: удочка/наживка/пассивки дают модификаторы `fishing.luck.<category|rarity>`; RngBus умножает веса на `(1 + luck/100)`. «Сокровищные» удочки тянут `fishing.treasure.weight` (Дноход: ×4 к сокровищам, но `maxFishRarity: uncommon` — кап модификатором, не if-ом).

## 4. Удочки и наживки

- **Удочки (тиры, предметы с ривен-роллами M03):** Бамбуковая → Ореховая → Стеклянная → Карбоновая → Мифриловая → «Поток» (легендарная). Параметры = статы шаблона + роллы: `fishingPower` (смещает веса редкости вверх), `treasureBias`, `minigame.zoneSize`, `maxFishRarity`, прочность.
- **Наживки (расходники):** Червь (база), Муха (+10% редкость), Икра (+25% редкость, −10% клёв), Светящийся мотыль (+50% к событиям), Легендарная приманка (гарант rare+). Наживка может быть УСЛОВИЕМ появления рыбы в пуле (`conditions` рыбы).
- Сокровища: сундук → таблица (ресурсы, предметы, карты сокровищ). События: «выпрыгнула русалка», «бутылка с запиской» — мини-события с выбором (данные).

## 5. Гейтованные рыбы и альбом

- Примеры: «Золотой карп» — Мифриловая удочка + Икра + уровень 20; «Ледяная нерка» — Светящийся мотыль + ачивка «Хозяин озера» (из M08); «Древний сом» — ачивка «Глубины» (босс слоя 3) + легендарная приманка.
- Альбом-коллекция: все виды рыб, счётчик пойманных, условия открытия заблокированных (правило «гейты показываем»), коллекционные награды за полноту — данные, награды через M15.
- Локации: пруд (старт) → река (навык рыболовства 10) — вторая таблица со своими рыбами; тег локации в контексте роллов.

## 6. Интеграция

- События: `cast.completed` (категория, что поймано, вес/качество), `fish.caught` (defId, редкость, качество — для XP, альбома, квестов).
- Провайдер: `baitProvider` (активная наживка), удочка — через `equipmentProvider` M02.
- TaskRegistry: `fishing.cast` (для работника-рыболова).
- Debug: `fish.cast`, `fish.tables`, `fish.force <fishId>`.

- [ ]Luck смещает веса: монте-карло по таблице с удочкой +40% luck — редкая категория тяжелее (допуск хи-квадрат).
- [ ] Гейт-рыба не попадает в пул без условия (10 000 роллов — ноль попаданий).

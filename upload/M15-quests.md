# M15 — Квесты, ачивки, гейты (движок условий)

> Фаза 2 · объём M · вход: 01-CORE, 02-BUSES, 03-DATA, M01, этот файл. Движок — декларативный: НИ ОДНОГО обработчика конкретного квеста или ачивки в коде; только данные + счётчики ядра + события.

## 1. Цель модуля

Три сущности на одном движке: ежедневные и еженедельные квесты (из пулов по dailySeed), сюжетные цепочки (шаги открывают системы), ачивки (счётчики → награды → `unlockFlags`-гейты для магазина/рыб/слоёв/систем). Прогресс трекается ИСКЛЮЧИТЕЛЬНО по событиям шины.

## 2. Движок

- `QuestDef` / `AchievementDef` (03-DATA §9): шаги с `condition: Condition` и наградами `Reward[]`.
- Подписки манифеста: события из каталога (02-BUSES §4) → счётчики ядра (M01 §6) → переоценка активных условий. Условие — общим `Condition`-оценщиком (03-DATA §2): `{t:'any'}` по «собрано урожаев ≥ N», «поймано рыб X ≥ K» (фильтр по defId), «успешных заточек ≥ M», «продано на бирже ≥ J золота».
- Новая механика даёт квестам прогресс автоматически: если модуль публикует событие — квест-шаблон с фильтром по нему просто добавляется ДАННЫМИ.
- Награды: через TransactionService + `passivePoint` (событие для M14) + `flag` (в ачивках) + `xp`.

## 3. Ежедневные и еженедельные

- Daily: 3 квеста роллятся в 00:00 из пула ~30 шаблонов («Собери 20 единиц урожая», «Поймай 5 рыб», «Сделай 3 попытки заточки», «Пройди 1 забег шахты», «Накорми всех рыб»). Награды: золото + XP + сундучок ресурсов. 1 бесплатная замена квеста в день (кнопка — данные).
- Weekly: 3 квеста-цепочки из 3–4 условий, крупные награды: уникальные предметы, очки пассивок, купоны магазина.
- Прогресс дня не переносится; невзятые награды пропадают (мягко: напоминание в 22:00 — событие для UI).

## 4. Цепочки (сюжетные)

- «Восстановление хутора» — обучающая: 15 шагов (первая вспашка → первый работник → первый босс), шаги открывают системы по очереди — главный источник «гейтов по мере прохождения». Шаг цепочки может: выдать предмет, разблокировать систему (`flag`), показать страницу текста (данные).
- «Тайна глубин» (шахта, кульминация на боссе слоя 5), «Гость с озера» (мутации), «Соседи» (подготовка к деревне).
- Завершение цепочки — церемониальное событие (данные для UI-экрана).

## 5. Ачивки

- `AchievementDef`: условие по счётчикам, награды, `unlockFlags` — флаги, на которые смотрят гейты M04 (ассортимент), M07 (рыбы), M12 (слои), M16 (жители).
- Стартовый набор ~40 в `content/achievements.ts`; hidden-ачивки (пасхалки) поддерживаются.
- Примеры: «Первый улов» (поймать 1 рыбу — гейт наживок), «Хозяин озера» (вывести рыбу A+ — гейт «Ледяной нерки»), «Глубины» (убить босса слоя 3 — гейт «Древнего сома»), «Агроном» (100 урожаев — гейт солнечника), «Постоянный клиент» (100 покупок — скидка 04-DISCOUNTS).

## 6. Интеграция

- События: `quest.progress/completed`, `achievement.unlocked` (id, name, rewards — для тостов и журнала).
- API: `quests.list(type)`, `quests.claim(id)`, `quests.rerollDaily(id)`, `quests.chainProgress(chainId)`.
- Провайдер: `questFlagsProvider` — флаги, которые сами что-то модифицируют (редко; обычно флаги читают гейты-оценщики).
- Debug: `quests roll`, `quests complete <id>`, `ach unlock <id>`, `flags list`.

## 7. Приёмка и тесты

- [ ] Ноль спец-обработчиков: добавление нового квеста/ачивки в данных поднимает прогресс без пересборки (интеграционный тест).
- [ ] Daily детерминирован по dailySeed; замена — 1/день; после `time +1d` — новый набор.
- [ ] Флаг ачивки открывает реальный гейт: тест с фикстурой магазина (item с `unlock: achievement`).
- [ ] Цепочка: шаги идут строго последовательно; награды выдаются один раз (идемпотентность).
- Границы: счётчики — ядро/M01; UI-журнал — фаза 6; контент цепочек фаз 3–5 добавляется по мере систем.
